Movie Magic

Movie Magic is a web-based movie ticket booking application that allows users to browse movies, view movie details, book tickets, and manage their bookings.

Features

- User registration and login
- Browse available movies
- View movie details
- Select and book tickets
- Payment page
- Booking confirmation
- User profile and dashboard
- Admin dashboard

Technologies Used

- Python
- Flask
- MongoDB
- HTML
- CSS
- JavaScript

How to Run

1. Clone the repository.
2. Install the required Python packages.
3. Configure the MongoDB connection.
4. Run the Flask application.
5. Open the application in a web browser.

Purpose

This project was developed to understand web application development, database integration, user authentication, and movie ticket booking workflows.
